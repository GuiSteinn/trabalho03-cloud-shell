Trabalho 03

Linux, Shell Script e Automacao Operacional

Este ambiente simula a operacao Linux de um sistema de reservas de hotel em cloud.

01

Container Ubuntu

O Docker reproduz uma instancia Linux isolada, configurada de forma repetivel pelo Dockerfile e Docker Compose.

02

Apache e deploy

O site estatico e copiado de /app/source para /var/www/html, com validacao e log da publicacao.

03

Operacao automatizada

Scripts cuidam de atualizacao, estrutura, backups, processos, monitoramento, usuarios, permissoes e relatorios.

04

Persistencia

Dados operacionais usam volume Docker; backups e logs ficam mapeados para pastas do repositorio.

Fluxo tecnico

Como a solucao funciona
